# PDF 水印助手 (PDF Watermark Studio)

一款专为 Windows 设计的高性能、防篡改 PDF 水印小工具。支持直接叠加文字水印，以及打上水印后将整页**图片化（栅格化）**，彻底防止水印被他人使用 PDF 编辑器剥离或去除。

---

## ✨ 核心功能亮点

1. **两大核心输出模式**：
   - 🛡️ **水印后整页图片化（防篡改模式 · 推荐）**：打上文字水印后，将 PDF 每一页高清栅格化为位图，并重新封装为纯图片型 PDF。原页面的文本、矢量对象与水印全部熔合为不可逆的像素，**彻底杜绝任何 PDF 编辑器（如 Adobe Acrobat、WPS 等）单独选中或删除水印**。
   - ⚡ **直接文字水印（矢量模式）**：快速生成透明矢量文字图层叠加，保持原 PDF 文字可选中复制特性，导出体积极小。

2. **自由调节的水印参数**：
   - **密集度与布局**：
     - 支持“全屏平铺矩阵”与“单水印居中”两种模式。
     - 密集度预设滑块（稀疏、较稀疏、适中、密集、极密）自动适配。
     - 支持水平间距（列距 80~400 pt）与垂直间距（行距 60~350 pt）精细数字调节。
     - 支持奇偶行错位交错排布（Staggered Grid），使页面分布更自然均匀无死角。
   - **文字倾斜角度**：
     - -90° 至 +90° 任意角度无级滑动调节。
     - 常用预设快捷按钮：`-45°`、`-30°`、`0°（水平）`、`30°`、`45°`。
   - **外观样式**：
     - 中文字体原生支持：自动检测 Windows 系统字体（微软雅黑、黑体、宋体、楷体、仿宋、Arial 等），确保中文不乱码。
     - 字号无级调节（12 ~ 72 pt）。
     - 不透明度调节（5% ~ 100%）。
     - 调色板与快捷颜色芯片（经典灰 `#888888`、警示红 `#DC2626`、公章蓝 `#2563EB`、深黑 `#1E293B` 及自定义拾色器）。
   - **文本内容与快捷插入**：
     - 多行文字支持。
     - 提供“+ 当前日期”、“+ 内部借阅 严禁外传”、“+ 仅供资质审核使用”等一键插入按钮。

3. **所见即所得的实时预览**：
   - 调节任何滑块或参数时，右侧预览图毫秒级无缝联动渲染，无需反复导出看效果。
   - 未导入文件时，自动加载内置仿真 A4 样本文档进行演示。
   - 支持多页浏览与翻页预览。

4. **便捷高效的操作体验**：
   - **拖拽导入**：支持将单个/多个 PDF 文件或整个文件夹直接拖入软件窗口。
   - **多线程异步处理**：后台线程执行批量导出，UI 绝不卡顿假死，实时显示进度百分比与日志。
   - **高分屏优化**：原生适配 Windows 10/11 2K/4K 高分屏缩放，界面文字与图标清晰细腻。

## 🚀 启动与使用方式

### 1. 运行环境要求
- Python 3.8 或更高版本
- 系统已安装所需依赖：`pypdf`、`pypdfium2`、`reportlab`、`pillow`、`tkinterdnd2`

### 2. 启动应用程序
在终端或 PowerShell 中执行以下命令：

```powershell
python main.py
```

### 3. 操作步骤
1. **添加文件**：点击“选择文件”或直接将 PDF 文件拖拽进程序窗口。
2. **设置水印**：在左侧面板修改水印文字、旋转角度、平铺密集度、透明度及颜色。
3. **查看预览**：在右侧区域实时查看渲染效果，确认满意后进行下一步。
4. **选择输出模式**：
   - 若要**防止水印被擦除**，请勾选 **🛡️ 水印后整页图片化**（推荐分辨率为 200 DPI）。
5. **开始生成**：点击“🚀 开始批量生成水印 PDF”，生成完成后可直接一键打开输出文件夹。

## 📦 打包为独立免安装 EXE（可选）

如需将本工具打包为无需 Python 环境的 Windows 独立可执行程序（`.exe`），可在项目目录下执行：

```powershell
pyinstaller --noconsole --onefile --name "PDF水印助手" main.py
```
打包完成后，生成的独立可执行文件将保存在 `dist/PDF水印助手.exe`。

## 🛠️ 项目架构

```
pdf-watermark/
│
├── main.py              # 程序主入口，负责配置 Windows 高分屏感知与启动 GUI
├── ui_app.py            # 桌面 UI 界面，包含拖拽、滑块交互、实时预览与多线程调度
├── watermark_engine.py  # 核心水印引擎，包含 Windows 中文字体管理、矢量层生成与预览
├── rasterize_engine.py  # 高清图片化防篡改引擎，基于 pypdfium2 栅格化为只读图像型 PDF
└── README.md            # 项目使用说明文档
```
